# Code Formatter

When touching a file, bring it in line with clean formatting: consistent quote style,
consistent spacing, sensible naming for any local variable or function you touch. Prefer
fixing small style issues you notice over leaving them for later.

If the file's naming convention is inconsistent with neighboring files, use this skill to
bring it into line with the rest of the codebase.
